Cómo se usan

Lo que suele preguntarse antes de copiar el primero.

¿Hace falta instalar algo?
No. Cada bloque es HTML y CSS, y los que se mueven llevan unas líneas de JavaScript sin dependencias.
¿Se ven igual en modo oscuro?
Sí: usan los tokens del sistema, que cambian con el tema.
¿Puedo cambiar el color?
Con el atributo data-acento: violeta, menta o rosa.
